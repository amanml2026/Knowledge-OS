# Knowledge OS

Knowledge OS is a conceptual learning platform that helps users organize, visualize, and test their knowledge using AI. It uses Google's Gemini API to enrich learning experiences and provide intelligent feedback.

## Features
- **Knowledge Graph Visualization:** Explore concepts and their relationships interactively.
- **AI-Powered Learning:** Get summaries, explanations, and quizzes generated by Gemini.
- **Progress Tracking:** Monitor your mastery of different concepts over time.
- **Resilient AI Integration:** Falls back to a safe mock mode when AI is unavailable.

## Technologies Used
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, Recharts, React-Force-Graph-2D.
- **Backend:** FastAPI, Python, SQLAlchemy, SQLite, `google-genai` SDK.

## Getting Started

### 1. Backend Setup (FastAPI)
1. Open a terminal and navigate to the `backend` directory:
   ```bash
   cd backend
   ```
2. Create and activate a Python virtual environment:
   ```bash
   # Windows
   python -m venv venv
   .\venv\Scripts\activate

   # macOS/Linux
   python3 -m venv venv
   source venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Configure your environment:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Open `.env` and add your `GEMINI_API_KEY`. You can get a free key from Google AI Studio. **Never commit your `.env` file.**

5. Start the backend server:
   ```bash
   uvicorn main:app --reload
   ```

### 2. Frontend Setup (React/Vite)
1. Open a new terminal and navigate to the `frontend` directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Running Tests
To verify your Gemini API key is configured properly, run the test script in the `backend` directory:
```bash
cd backend
python test_gemini.py
```

## AI Fallback & Quota Exhaustion
Knowledge OS is designed to be resilient. If you do not provide a `GEMINI_API_KEY`, or if your API quota is exhausted (e.g., encountering a 429 error), the application will gracefully fall back to a "Mock Mode."
- In Mock Mode, you will receive predefined responses and alerts asking you to set your API key.
- The application will not crash, and all non-AI functionalities (like viewing the graph and managing settings) will remain available.
- **Note:** Users must provide their own eligible Gemini API access for full functionality.

## Known Limitations and V2 Roadmap
- **No Authentication:** V1 does not have a login system or multi-user support. All data is saved to a local SQLite database (`backend/knowledge_os.db`). Authentication is planned for V2.
- **Local Storage Only:** Data is intentionally kept local. Cloud synchronization will be introduced in future updates.
